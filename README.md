# Simple Interest Calculator

## Description

This project is a simple interest calculator.

It calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest
- Time period

## Formula

SI = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest
- T = Time period

## Example

If:

Principal = 1000  
Rate = 5%  
Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Therefore, the simple interest is **100**.
